   运动的合成与分解演示实验室 - 跨设备/跨平台离线使用说明
========================================================================

【适用场景】
本离线绿色包专为多媒体教室大屏、电子白板、无网络环境的多媒体讲台、
教师个人 Windows 笔记本电脑以及平板教学（Android 安卓平板 / iPad）设计。
100% 纯本地离线运行，无需连接互联网，无需安装任何开发环境或运行库！

------------------------------------------------------------------------
【一、Windows 电脑 / 教室多媒体一体机（推荐两种打开方式）】
------------------------------------------------------------------------
方式 1（极力推荐 · 完整性能体验）：
   👉 在解压后的文件夹内，双击运行【 一键在Windows运行.bat 】
   脚本会自动在后台启动 Windows 内置微型本地服务，并自动调起默认浏览器
   （Edge / Chrome / 360 / Firefox 等）全功能秒开运行！

方式 2（免脚本双击秒开 · 防教室杀软拦截）：
   👉 直接双击打开【 单文件无需服务器_双击即开.html 】
   如果教室一体机或学校电脑开启了严格安全管控（禁止运行 .bat 脚本），
   直接双击此单文件版，任何浏览器双击即开，无需本地服务！

------------------------------------------------------------------------
【二、平板设备（Android 安卓平板 / 华为鸿蒙 / iPad）】
------------------------------------------------------------------------
由于移动平板浏览器的安全沙箱机制，直接在文件管理器中点击普通多文件 HTML 
容易被浏览器报 CORS 跨域拦截导致白屏。我们为您提供了两种极简解决方案：

方案 1（极力推荐 · 独立单文件版）：
   👉 在平板文件管理器或网盘下载中，直接点击打开：
      【 单文件无需服务器_双击即开.html 】
   全部脚本、样式、字体与运动矢量引擎已 100% 内嵌在单个文件中，不依赖外部文件，
   使用平板自带浏览器或 Chrome / Edge / Via 直接点击即可离线全屏运行！

方案 2（免下载 · PWA 桌面应用脱机秒开）：
   在有网络时通过平板浏览器访问公网网址，点击浏览器菜单「分享 / 更多」➔「添加到主屏幕」，
   即可在平板桌面生成专属 App 图标，后续断网脱机也能像独立 App 一样全屏秒开！

------------------------------------------------------------------------
【三、常用课堂演示快捷键（连接键盘时）】
------------------------------------------------------------------------
- 空格键 (Space)：播放 / 暂停
- 方向键 (← / →)：单帧高精度步进微调 (±0.05s)
- 字母键 (R)：复位到初始时刻 t=0
- 按键 F11：进入全屏沉浸式授课展示模式
- 鼠标滚轮 / 触摸屏双指手势：放大微观细节或缩小宏观轨迹全貌
