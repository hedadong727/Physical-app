========================================================================
   运动的合成与分解演示实验室 - Windows 电脑端独立离线使用说明
========================================================================

【适用设备】
  Windows 11 / Windows 10 / Windows 7 / 教室希沃白板 / 电子触摸一体机

【解压与使用方法】
1. 下载后请先【解压整个压缩包】（不要直接在压缩包内双击）：
   - 鼠标右键点击压缩包 -> 选择「全部解压缩...」或「解压到当前文件夹」。

2. 解压后有以下两种运行方式：

   ★ 推荐方式一（功能最全、速度最快）：
     双击打开文件夹中的【一键在Windows运行.bat】。
     - 该脚本会自动检测系统中的 Edge 或 Chrome 浏览器，并在独立沙箱中安全启动实验室。
     - 即使学校电脑没有联网，也能完全离线秒开！

   ★ 极简方式二（免运行脚本、不怕杀毒软件拦截）：
     双击打开【单文件无需服务器_双击即开.html】。
     - 此文件将全部代码、样式与图标 100% 内嵌封装。
     - 无论用 Edge、Chrome、360 浏览器还是火狐，双击直接运行，绝不白屏！

【常见问题排查】
Q: 为什么双击 index.html 会白屏？
A: 现代浏览器的安全策略默认对本地文件 (file:// 协议) 限制 ES 模块加载。
   解决方案：请直接双击【单文件无需服务器_双击即开.html】或双击【一键在Windows运行.bat】即可，不要直接双击普通的 index.html。

Q: 电子白板上如何放大/缩小？
A: 支持多指捏合放大缩小，也可点击右侧工具栏的「＋」「－」放大缩小按钮。
